# Issue Labeling Rules

Default-label: triage

## Categories

| Label | Description | Keywords |
|-------|-------------|----------|
| bug | Something isn't working | bug, error, crash, fail, broken, not working, exception, issue, regression |
| feature | New feature request | feature, request, enhancement, add, new, implement, support, proposal |
| question | Question or help needed | question, how to, help, confused, documentation, explain, guide |
| documentation | Documentation improvement | docs, documentation, readme, typo, spelling, grammar, example |
| performance | Performance related | slow, performance, speed, latency, memory, cpu, optimize, benchmark |
| security | Security related | security, vulnerability, cve, xss, injection, auth, permission, access |
| ui | User interface related | ui, ux, design, layout, style, css, display, visual, responsive |
| infra | Infrastructure or DevOps | deploy, ci, cd, docker, kubernetes, pipeline, build, config, infra |
